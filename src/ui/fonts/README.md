# osifont

`osifont.ttf` ist osifont (https://github.com/hikikomori82/osifont), eine freie
Schrift nach ISO 3098, in der Fassung `osifont-lgpl3fe.ttf`:
GNU LGPL Version 3 mit GPL-Font-Ausnahme. Die Schrift wird unverändert
mitgeliefert und beim Export in SVG, PNG und PDF eingebettet; die
Font-Ausnahme erlaubt das, ohne dass die damit erstellten Dokumente unter die
Lizenz fallen.

FluidPlan nutzt sie für alle Texte auf dem Blatt (DIN ISO 1219-1, 5.13:
Beschriftung nach ISO 3098-5, Schriftform CB).
